# ภาพรวม & ข้อควรระวัง

คู่มือนี้พาติดตั้งระบบลาออนไลน์ **eLeave** ตั้งแต่ต้นบนเครื่องใหม่ เลือกได้ 2 แบบ:

- **[ติดตั้งแบบ Native](./native)** — ลง Node.js + MySQL เองในเครื่อง เหมาะกับการทำความเข้าใจระบบทั้งหมด
- **[ติดตั้งด้วย Docker](./docker)** — ยกทั้งชุดด้วยคำสั่งเดียว เหมาะกับการทดสอบ/ติดตั้งเร็ว

เมื่อระบบรันแล้ว ทำต่อที่ **[การใช้งานครั้งแรก](./first-use)** (สร้างผู้ดูแล → นำเข้าผู้ใช้ → มอบบทบาท)

## ⚠️ อ่านก่อนเริ่ม

::: warning เวอร์ชันฐานข้อมูลสำคัญมาก
ต้องเป็น **MySQL 8.0+** หรือ **MariaDB 10.5+** เท่านั้น — สคริปต์ migration ใช้คำสั่ง `ALTER TABLE ... RENAME INDEX` ที่ **MariaDB 10.4 (เช่นที่มากับ XAMPP) รันไม่ผ่าน** (error 1064)
:::

- ระบบ **เข้าสู่ระบบด้วย Google OAuth เท่านั้น** — ผู้ดูแลคนแรกต้องเป็นอีเมล Google จริงที่ล็อกอินได้ (บัญชีอินเตอร์เน็ตที่ออกโดยมหาวิทยาลัย)
- โปรเจกต์แยกเป็น **2 ส่วน:** `backend/` และ `frontend/`

## 🗺️ ภาพรวมขั้นตอน (แบบ Native)

| Phase | ทำอะไร | ผลที่ควรได้ |
|-------|--------|-------------|
| 0 | ติดตั้งเครื่องมือ: Git, Node.js, MySQL 8 | คำสั่งพื้นฐานใช้งานได้ |
| 1 | สร้างฐานข้อมูลเปล่า | มี database `eleave` |
| 2 | ตั้งค่า Backend (`.env` + `npm install`) | `.env` ครบ, ติดตั้ง dependency แล้ว |
| 3 | สร้าง schema + ข้อมูลหลัก (`npm run setup`) | ตารางมี roles/แผนก/ประเภทการลา ฯลฯ |
| 4 | สร้างผู้ดูแลคนแรก (CLI) | มีบัญชี SUPER_ADMIN |
| 5 | รัน Backend + Frontend | เห็นหน้า Login |
| 6 | ตั้งค่า Google OAuth | ล็อกอินเข้าระบบได้จริง |
| 7 | นำเข้าผู้ใช้ + มอบบทบาทผู้อนุมัติ | ระบบพร้อมใช้งานจริง |

::: tip
ถ้าใช้ **Docker** จะข้าม Phase 0–1 (ไม่ต้องลง Node/MySQL เอง) — ดู [หน้า Docker](./docker) ได้เลย ส่วน Phase 7 (การใช้งานครั้งแรก) ทำเหมือนกันทั้งสองแบบ
:::
